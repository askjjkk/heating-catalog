# Батареи и обогреватели

Простой демонстрационный каталог. HTML, CSS, JavaScript и локальные SVG, без библиотек, сборки, внешних шрифтов и аналитики.

Пользователь попросил простой сайт без предоставления названия магазина, телефонов, реальных товаров и цен. Поэтому категории и иллюстрации показаны как пример ассортимента. Цены, наличие, доставка и гарантии не выдуманы. Оплата и отправка заказов не подключены.

Работают фильтры каталога, выбор категории в запрос и копирование текста запроса. Если копирование недоступно, появляется выделенное поле для ручного копирования. Данные не сохраняются и не отправляются.

Для запуска открыть index.html. Для будущего магазина добавить реальные модели, цены и контакты в index.html.
